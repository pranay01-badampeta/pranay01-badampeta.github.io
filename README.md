# Pranay Badampeta — made of data

A 3D portfolio: ~30,000 particles form Pranay's portrait from his photo, then morph into a neural
network, a DNA-style helix, a solar-panel array, a price chart and a galaxy as you scroll.

React + TypeScript + Tailwind CSS + GSAP + Three.js (custom shaders), built with Vite.

- `npm install`, then `npm run dev`.
- `npm run build` creates the static site in `dist/`.
- Text: `src/content.ts`. Shapes: `src/scene/shapes.ts`. Morphing shader: `src/scene/createScene.ts`.
